# Pocket Deck

**Tu celular se convierte en un panel de botones para tu PC.** Abre programas, carpetas y páginas sin buscarlos en Windows.

**[Probar los botones sin instalar](https://albertovj.github.io/pocket-deck-app/demo.html)** · **[Descargar para Windows](https://github.com/AlbertoVJ/pocket-deck-app/releases/latest/download/PocketDeck-Windows-x64.zip)** · [Guía rápida](GUIA.md)

![Pantalla de Pocket Deck](preview.png)

## Pruébalo en tres pasos

1. Descarga el ZIP y **extrae toda la carpeta**.
2. Abre **Probar-interfaz.html** para explorar la demo, o **PocketDeck.exe** para conectar tu PC.
3. Para usarlo de verdad, abre la [app del celular](https://pocket-deck-oxy.albertovj6969.chatgpt.site/) en Chrome de Android, pulsa **Conectar PC** y escribe el código que muestra Windows.

La PC y el celular necesitan estar en el mismo Wi-Fi. Node.js viene incluido: no tienes que instalarlo ni escribir comandos.

## Qué puedes hacer

- Organizar nueve botones por carpeta.
- Abrir programas, carpetas y enlaces de Windows desde el celular.
- Cambiar nombres, iconos y acciones con el editor de la PC.
- Dejar el componente de Windows junto al reloj y salir cuando termines.

La demo del navegador muestra qué harían los botones; **no controla tu PC**. La conexión real requiere una red y un navegador móvil compatibles. La prueba completa con teléfonos ajenos sigue pendiente; si lo pruebas, cuéntame el modelo y resultado.
